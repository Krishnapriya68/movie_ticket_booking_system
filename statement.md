# Project Statement

## Problem Statement
Booking movie tickets manually can make it difficult to keep track of movies, available seats, bookings, cancellations and ticket amounts.

This project creates a simple Python-based Movie Ticket Booking System that allows a user to manage these basic activities from a menu-driven program.

## Scope
The project focuses on basic movie ticket booking. It stores movie and booking information in a JSON file instead of using a large database.

## Target Users
- Students learning Python
- Small movie/cinema booking demonstrations
- Beginners learning modular programming and file handling

## High-Level Features
1. Display available movies
2. Display available seats
3. Book a seat
4. Cancel a booking
5. Calculate ticket amount
6. Display current bookings

## Main Modules
- Movie display module
- Seat booking and cancellation module
- Billing module
- Data storage module
- Input validation and utility module
